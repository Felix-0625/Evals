# 首版阶段验收依据

核对依据为 Guide.md、Plan.md 和 development.md，范围不随现有测试缩减。下表中的“通过”仅对应注明的验证范围；未执行、间接证据或缺失实现均不计为通过。运行产物位于本机 `artifacts/`，不会把合成用例结果作为生产收益。

以下为阶段实施时的验收依据；最新发布门禁和真实模型验收见 [当前状态](implementation-status.md)。首版本机开发与验收已完成。当前支持 Windows、单可信操作者、本地文件存储，以及已登记的应用配置和提示资产。M0–M4 的证据列于下表，M5 的后续观测、案例回流和三组策略对照已实现。当前产品回归 100 项通过，安装、原生评测、Scout、GEPA、控制、Viewer 和两套隔离真实应用均有运行记录。实际模型质量和持续收益按文末范围保留为未验证。

# 当前实现与验证状态

2026-11-07，版本 0.1.0。发布范围为本机单可信操作者，GitHub 公开源码与 Release。M0–M5 的登记能力已实现；实际效果按下面的证据范围报告。

| 范围 | 当前结果 |
| --- | --- |
| 内核与安装 | 固定 Inspect、Scout、GEPA 和前端来源；四个 wheel 构建并在独立环境安装，103 个运行依赖兼容；安装后 8 轮原生评测与 Scout 重扫通过。 |
| 自有业务回归 | 105 项通过；覆盖协议、八维分母、预算、暂停/取消、原生恢复、评分、采用回执、回归案例和策略门槛。 |
| 前端 | 36 项格式/类型/静态任务通过，11 个工作区共 6,226 项测试通过；Inspect 与 Scout Viewer 均重新构建。 |
| 真实模型 | VeraAgent 与 NexRAG 分别在真实 deepseek-flash 下完成 4 轮隔离基线及 1 次预检；NexRAG 使用生成公开知识，VeraAgent 使用临时代码沙箱。 |
| 安全与许可 | 前端最初 4 条依赖中危公告已修复；最终前后端依赖审计无已知漏洞。已审查自有信任边界、字体、依赖声明和拟提交文件中的凭证模式。 |
| RSI | 受控候选、独立验证、采用/回滚、后续观测和三臂策略对照已实现并有确定性回归；长期真实模型改进收益尚未验证。 |

最初的超时、区域格式断言失败与真实模型失败均保留在本机原始记录中，修复后重跑分别保存。回归、真实模型和生产收益不是同一类证据。
